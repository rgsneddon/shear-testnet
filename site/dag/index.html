What this DAG is

Thin batched Shear DAG. One vertex per worker per round from valid hashes.

Parents = that worker’s previous vertex + last committed dag_root.

Only the selected set on the winning tip mints. 1 valid hash = 1 tx = 10−11 SHE, auto-paid, no claim button. Immature until 6-conf.

What it is not

  • Not one vertex per nonce
  • Not GHOSTDAG, not a second paid lane
  • Not “all hashes this round” / client hash-rate glitter
  • Not a 50-dot spray
