How to mine

  1. Install Continuum 0.70 and use Copy dest. The paid login starts with ssa1.
  2. Download the zip that matches this machine. Leave every file in one folder. Windows needs the OpenSSL DLLs beside ShearK-Miner.exe. The other packs keep ShearK-Miner beside the OpenSSL libraries.
  3. Open example.bat on Windows, or example.sh on Linux, Arch, Fedora, openSUSE, and macOS. Replace YOUR_SSA1 with Copy dest. Set --threads to this machine's logical CPUs. A typed .worker is optional and pays the same address. Two machines need two worker names.
  4. Windows: save, then double-click example.bat. Everywhere else: chmod +x ShearK-Miner example.sh and run ./example.sh.
  5. On a new machine, run --selftest once. The digest must be 98818c31d739ef821db0242f76bd244b96f1fb5049d27ea9a192e95c67b39a8b.
  6. A good pool start prints tls verify ok and a job height. accepted climbs. Each accepted floor share is paid to that dest on the next sealed block.

Public pool is stratum+ssl://pool.shear.digital:443. TLS uses the current Let's Encrypt and ISRG roots, or the OS store. Do not pass --tls-pin. There is no --tls-insecure. Localhost solo stays cleartext at stratum+tcp://127.0.0.1:1111 after the node reports ibd=false. Those solo lines are commented in the sample launchers. she1 without --dest is unpaid. Never use shear1. The live book is shear-testnet-v10. --print-config still reports magic shear-testnet-v4. The header you hash comes from the job.

Pool path

Start mining on pool

Get an ssa1 Copy dest from Continuum or the pool UI, then:

./ShearK-Miner --selftest
./ShearK-Miner --pool stratum+ssl://pool.shear.digital:443 --user YOUR_SSA1 --threads 8

Windows: use ShearK-Miner.exe with the same flags. The Windows zip ships libssl and libcrypto beside the exe. 2.8 keeps a bare ssa1. A typed YOUR_SSA1.suffix is optional and pays the same address. Public pool is TLS. Localhost solo and the migrate port stay cleartext TCP.
