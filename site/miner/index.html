Pool path

Start mining on pool

Get an ssa1 Copy dest from Continuum or the pool UI, then:

./ShearK-Miner --selftest
./ShearK-Miner --pool pool.shear.digital:1111 --user YOUR_SSA1 --threads 8

Windows: use ShearK-Miner.exe with the same flags. 2.6 keeps a bare ssa1. A typed YOUR_SSA1.suffix is optional and pays the same address. Stratum is cleartext TCP unless TLS sits in front.
