Continuum steps

  1. Install Continuum 0.59 from the release channel you trust for shear-testnet-v5.
  2. Set a password and store it offline. There is no recovery email.
  3. Create or restore a wallet. Note your she1 receive address.
  4. Export backup as shewall.bin and keep it offline.
  5. Wait for Continuity before treating a balance as spendable.
Mining is not inside Continuum. Use ShearK separately — see Mine.
