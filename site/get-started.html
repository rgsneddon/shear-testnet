Get started

Install Continuum 0.65, keep shewall.bin, then let a node fill Shearview. Deep OS notes live in the docs. The node download is Shear Sentinel v15.

Continuum steps

  1. Install Continuum 0.65 from the wallet hub (Windows, Linux, Arch, Fedora, Android) for shear-testnet-v10. Android has no full node: stay on Connect Bare. A desktop node is the separate Shear Sentinel v15 zip.
  2. Set a password and store it offline. There is no recovery email. shear restore opens a password-sealed shewall.bin. It does not import a raw spend seed.
  3. Create or restore, then note your she1. Connect Bare is the default. A local node is the same read: the node walks the book and returns only notes sealed to your dest, through the tip. Payments to anyone else stay out. Empty blocks do not appear.
  4. Export backup as shewall.bin from Closure and keep it offline. On Android, export before you uninstall an older install, then sideload the 0.65 APK.
  5. Wait for Continuity. Spendable is opened coins with 9 confirmations. Younger seals stay pending. A pool balance does not become Spendable. Mine with ShearK 2.6 and Copy dest; seals made while the wallet was closed show up when you open it.
Mining is not inside Continuum. Use ShearK separately — see Mine.
