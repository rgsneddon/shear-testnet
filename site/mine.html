Mine

Choose pool or solo. Miner binary is ShearK 2.8 — separate from Continuum 0.71. The node (Shear Sentinel v18) is what the wallet reads. Downloads live on the wallet, node, and miner hubs. How-to: https://shear.digital/docs/#/surfaces.

Recommended

Pool path

Connect ShearK to stratum. Copy your ssa1 dest from Continuum or the pool UI.

stratum+ssl://pool.shear.digital:443
  1. Open pool.shear.digital
  2. Paste / Copy dest (ssa1…)
  3. Point ShearK at the stratum host:port above
  4. Watch shares. Open Continuum. Each seal for your dest lands in Shearview, including ones from while it was closed. Spendable waits for 9 confirmations of an opened coin.
Open pool → ShearK miner →

Solo path

Run a synced node, then solo mine. More ops, same algo.

npm run solo
  1. Install Shear Sentinel v18 or build from the node page. Sync shear-testnet-v11 until ibd=false.
  2. Run npm run solo so stratum listens on 127.0.0.1:1111. Do not use npm run pool.
  3. Point ShearK at that port with Copy dest (--user YOUR_SSA1). A typed suffix is optional.
Deep solo OS deps and troubleshooting live in official docs — not duplicated here.
