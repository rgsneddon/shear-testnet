Optional. Nodes do not pull this automatically. They sync height 1, 2, 3, … to the tip. Magic shear-testnet-v6. One file pair, overwritten on the snapshot ladder (first at height 200, then every 200 blocks).

What this is

A pruned prefix of the live book: headers, coinbase, sealed transfers. Not a history of snapshots. Empty datadir only. A fake file is a different book. After the node is at the tip, Continuum 0.61 reads notes for your dest from 127.0.0.1:18332. Wallet download: https://shear.digital/wallet/. Node download: https://shear.digital/node/ (Shear Sentinel v11). How-to: https://shear.digital/docs/#/surfaces.

Use only this host. After apply, the node must still reach the live tip hash on the public seeds (p2p.shear.digital:30303, r2r.shear.digital:30303, b2b.shear.digital:30303).

How to apply (manual)

Default node node/src/node.js never hooks a bootstrap. To import this pair onto an empty datadir:

mkdir -p ~/shear-bootstrap
cd ~/shear-bootstrap
curl -fsSO https://boot.shear.digital/latest.json
curl -fsSO https://boot.shear.digital/latest.bin

export SHEAR_DATA="$HOME/.shear/testnet-v6"
rm -rf "$SHEAR_DATA"
node node/src/node.js --bootstrap="$PWD"

Same binary, P2P 30303, RPC 18332 loopback, magic shear-testnet-v6. Then it requests each later height until the tip. Mining (--solo) is refused until ibd=false.

If apply refuses

  • bootstrap_datadir_not_empty — you still have chain.bin or chain.jsonl. Use a new directory.
  • bootstrap_magic — not shear-testnet-v6.
  • bootstrap_dropped_txs — snapshot lost sealed txs. Full IBD from genesis instead.

Full IBD (default)

export SHEAR_DATA="$HOME/.shear/testnet-v6"
export SHEAR_NETWORK=shear-testnet-v6
export SHEAR_SEEDS=p2p.shear.digital:30303,r2r.shear.digital:30303,b2b.shear.digital:30303
node node/src/node.js

No --bootstrap. No automatic pull. Sequential sync from genesis, then stay at the tip.
