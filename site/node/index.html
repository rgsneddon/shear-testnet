Run a Shear node

Clone shear-testnet, build RandomX + crypto/native, sync to tip. Optional thin solo stratum. Continuum wallet downloads are on WALLET — this page is the node.

What is downloadable?

GitHub shear-testnet release 0.53 ships wallet assets only (Linux / Windows / Arch / Android). The full node is build-from-source via the repo path tree/main/node. Do not expect a node.zip on the release page.

Copy/paste install panes

Full validating node for shear-testnet-v5. There is no prebuilt node binary on GitHub releases — you clone and build from rgsneddon/shear-testnet (tip Continuum wallet is 0.53; node lives at node/ in that tree).

Beginner path (from tip site): OS deps → clone → RandomX + crypto/native → validating node → optional npm run solo (thin stratum on 127.0.0.1:1111). Continuum GUI is optional for RPC. Never npm run pool unless you are operating the public pool.

Commands below are lifted from tip site/index.html #solo-mine — do not invent alternate package lines.

Debian / Ubuntu x86_64. Node 20 from NodeSource; rustup for native ADMITv2.

sudo apt-get update
sudo apt-get install -y git curl build-essential cmake python3 pkg-config libssl-dev
# Node 20+
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
# Rust (native ADMITv2 / BP+)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
. "$HOME/.cargo/env"

Headers check — runtime Node is not enough; ls must show node_api.h. If it fails, install Node with headers (NodeSource / nodejs-devel), not a headerless binary.

node -v   # need 20+
node -e "console.log(require('path').join(process.config.variables.node_prefix||'/usr','include/node'))"
ls "$(node -e "process.stdout.write(require('path').join(process.config.variables.node_prefix||'/usr','include/node'))")/node_api.h"

NODE_INC recovery — do not find /usr only if empty (that sets NODE_INC=. and fails again with bare -I.):

# Prefer Node's own prefix; fall back to find near the node binary
export NODE_INC="$(node -e "const fs=require('fs');const p=require('path');const base=process.config.variables.node_prefix||'/usr';const d=p.join(base,'include/node');if(fs.existsSync(p.join(d,'node_api.h'))){process.stdout.write(d);process.exit(0)}process.exit(1)" 2>/dev/null || dirname "$(find "$(dirname "$(dirname "$(readlink -f "$(which node)")")")" /usr/local /usr -name node_api.h 2>/dev/null | head -1)")"
echo "NODE_INC=$NODE_INC"   # must be a real directory, NOT . or empty
test -f "$NODE_INC/node_api.h" || { echo "Still missing headers — reinstall Node with devel/include"; exit 1; }
make -C crypto/native

Then continue with clone / RandomX / crypto/native below.

node node/src/node.js --print-config
sudo cp deploy/shear-node.service /etc/systemd/system/shear-node.service
sudo systemctl daemon-reload
sudo systemctl enable --now shear-node
journalctl -u shear-node -n 20 --no-pager

You are done when a status line shows hashBackend=native, peers at least 1, and ibd=false with the height holding still. While the height is still climbing, ibd=true is catch-up, not a failure. The number on pool.shear.digital is the pool’s own book. Your node follows the public peers. Those two heights are not the same reading. Do not wipe /var/lib/shear/testnet-v5 because the pool page is taller. Add every seed you have; the node is not limited to one host.

1. Clone, RandomX, crypto/native

Same as README “Build your own node”. Run the Headers check in your OS tab first. If make still fails on node_api.h, use that tab’s NODE_INC recovery (do not find /usr into an empty NODE_INC=.).

git clone https://github.com/rgsneddon/shear-testnet.git
cd shear-testnet
git checkout 0.53
npm ci
cmake -S crypto/randomx -B crypto/randomx/build -DARCH=native
cmake --build crypto/randomx/build -j"$(nproc)"
make -C crypto/native
node node/src/node.js --print-config

--print-config must show "magic":"shear-testnet-v5", "admit":"ADMITv2", "mainnet":false.

2. Validating node (not the full pool)

Release 0.53. Bare node node/src/node.js is validator-only (P2P + loopback RPC). Put SHEAR_SEEDS in the same shell as the node. Outbound TCP to those seeds is required; opening inbound firewall 30303 alone does not sync. Startup does not pull a bootstrap. Leave SHEAR_BOOTSTRAP unset or 0. Do not npm run pool — that is the public-pool operator stack.

export SHEAR_DATA="$HOME/.shear/testnet-v5"
export SHEAR_NETWORK=shear-testnet-v5
export SHEAR_P2P_PORT=30303
export SHEAR_P2P_BIND=0.0.0.0
export SHEAR_RPC_PORT=18332
export SHEAR_RPC_BIND=127.0.0.1
export SHEAR_BOOTSTRAP=0
export SHEAR_REORG_HALT_DEPTH=0
export SHEAR_SEEDS=p2p.shear.digital:30303,r2r.shear.digital:30303,b2b.shear.digital:30303
node node/src/node.js

3. Thin solo stratum

Same shell, only after the node height has caught the public tip. npm run solo is node node/src/node.js --solo: validator + stratum on 127.0.0.1:1111. A solo block found while any peer is ahead is refused (syncing) and is not sealed. A bare ssa1 is the login. A typed ssa1.suffix is optional and pays the same address.

export SHEAR_STRATUM=1111
export SHEAR_STRATUM_BIND=127.0.0.1
npm run solo
