# Shear wallet 0.0.9

Testnet wallet. Tabs: Continuum, Flow, Resistance, Vortex, Shearview, Closure (G_{μν}). The Reserve lives under Vortex.

Backup file: encrypted `shewall.json`. Offer `she1`. Miner login is `she1` or `shp1`. Chain dests are `shp1` (`she1` never on chain). Rest-frame `shear1` is never a dest. Pool: `pool.shear.digital:1111`.

Continuum is spendable, pending transfers until the next block, and Copy ID. Shearview is confirmed transfers; tap a tx for its CTF printout on Resistance. This wallet does not mine.
