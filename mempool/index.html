Logarithmic spiral of txs

Sealed heights fall on r = ln(1 + n). Pending rings sit above them as counts and kinds, not dest+amount pairs. The gold hoop is in-flight Flow sends. The cyan hoop is miners on the network working the open round. Sealed hash-bonus vouts stay off the spiral so it stays readable; they still mint on-chain. This page reads the network mempool from every equal node — any pool or solo — not only the official pool. While this book has fewer than 10,000 notes the membership set is thin. Commission

When the gold hoop is empty it rests at the base of the lattice, wide around the circumference. Each pending send sits on a level set by its weight × levy: heavier work climbs toward the tip.

Filaments link those gold seats to the cyan miners packing the next block. Committed sends leave gold and appear under purple confirming rings, then as recovered blocks on the spiral. Sealed hash-bonus vouts stay off the spiral so a busy book does not pack it.

The charcoal field is a static fine square grid — Continuum Receive look. Data dots update from the live book; the camera slowly auto-orbits when you are not dragging.
